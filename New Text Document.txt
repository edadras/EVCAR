یک صفحه در وب اپ درست کن و این بخش را در آن اضافه کن استایل را با سایر بخش های وب اگ حفظ کن هر جا هم نیاز به API داشتی راهنمایی کن که آن را برای شما ارسال کنم :# مشخصات فنی کامل: EV Navigator — سیستم مسیریابی هوشمند خودروی برقی

## ۱. خلاصه پروژه

یک اپلیکیشن وب/موبایل که به رانندگان خودروهای برقی نشان می‌دهد:
- از موقعیت فعلی تا مقصد چقدر انرژی مصرف می‌شود
- در هر بخش از مسیر (سربالایی، سرازیری، باد، دما) مصرف چقدر تغییر می‌کند
- با شارژ فعلی به کجا می‌رسند و کجا باید شارژ کنند
- نزدیک‌ترین ایستگاه‌های شارژ کجاست و وضعیت آن‌ها چیست

[موبایل/مرورگر کاربر]
        │
        ▼

        │
   ┌────┴──────────────┐

### لایه‌های سیستم:

| لایه | مسئولیت |
|------|---------|
| Frontend | نمایش نقشه، نمودار ارتفاع، وضعیت شارژ |
| Backend Orchestrator | دریافت درخواست، فراخوانی APIها، ترکیب داده |
| Smart Cache Layer | تصمیم‌گیری: آیا داده در DB هست یا باید از API بگیریم؟ |
| Persistent Storage | PostgreSQL — ذخیره دائمی تمام داده‌های گران‌قیمت |
| Hot Cache | Redis — ذخیره موقت داده‌های پرتکرار در RAM |
| Calculation Engine | محاسبه مصرف واقعی هر بخش مسیر |

## ۳. استراتژی هوشمند کش و ذخیره‌سازی (Smart Caching Strategy)

### ۳.۱ اصل کلی: کدام داده‌ها باید ذخیره شوند؟

| نوع داده | تغییرپذیری | TTL Redis | ذخیره در DB | دلیل |
|---------|-----------|-----------|-------------|------|
| ارتفاع زمین | هرگز تغییر نمی‌کند | ∞ | بله، دائمی | جغرافیا ثابت است |
| مسیر جاده‌ای (هندسه) | ندرتاً (سال‌ها) | 30 روز | بله، دائمی | جاده‌ها تغییر نمی‌کنند |
| مسیر Google (هندسه) | ندرتاً (سال‌ها) | 30 روز | بله، دائمی | polyline جاده دائمی است |
| ایستگاه‌های شارژ | هفتگی | 24 ساعت | بله، 7 روز | تعداد و مکان نسبتاً ثابت |
| آب‌وهوا | هر ساعت | 1 ساعت | بله، 2 ساعت | داده لحظه‌ای، نگهداری کوتاه |

### ۳.۲ سیستم سه لایه‌ای Cache

```
درخواست کاربر
      │
      ▼
┌─────────────────────────────┐
│  Layer 1: Redis (Hot Cache)  │  ← پاسخ در <1ms
│  داده‌های پرتکرار در RAM     │
└──────────────┬──────────────┘
               │ نبود در Redis
               ▼
┌─────────────────────────────┐
│  Layer 2: PostgreSQL (Cold) │  ← پاسخ در <10ms
│  ذخیره دائمی در دیسک        │
└──────────────┬──────────────┘
               │ نبود در DB
               ▼
┌─────────────────────────────┐
│  Layer 3: External API Call │  ← پاسخ در 200-2000ms
│  دریافت از اینترنت + ذخیره  │    + هزینه API
└─────────────────────────────┘
```

## ۵. سرویس Smart Cache (کد کامل)

```python
# smart_cache.py
import asyncio
import hashlib
import json
from datetime import datetime, timedelta
from typing import Optional, List, Dict, Any

import httpx
from redis.asyncio import Redis
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import text


class SmartCacheService:
    """
    سرویس مرکزی Cache — تمام تصمیم‌گیری‌های ذخیره/بازیابی اینجاست.
    
    اصل کار:
    1. ابتدا Redis چک می‌کنیم (سریع‌ترین)
    2. بعد PostgreSQL چک می‌کنیم (دائمی)
    3. اگر هیچ‌کدام نبود، از API خارجی می‌گیریم و در هر دو ذخیره می‌کنیم
    """

    def __init__(self, redis: Redis, db: AsyncSession):
        self.redis = redis
        self.db = db
        self.http = httpx.AsyncClient(timeout=15.0)

    # ─────────────────────────────────────────────
    # ارتفاع زمین
    # ─────────────────────────────────────────────

    async def get_elevations(self, points: List[tuple]) -> List[float]:
        """
        دریافت ارتفاع برای لیستی از نقاط.
        نقاطی که در DB هستند از DB، بقیه از API گرفته و ذخیره می‌شوند.
        """
        results = {}
        missing_points = []

        # مرحله ۱: تبدیل به کلیدهای گرد شده
        rounded = [(round(lat, 4), round(lng, 4)) for lat, lng in points]

        # مرحله ۲: بررسی Redis برای همه نقاط (pipeline برای سرعت)
        redis_keys = [f"elev:{lat},{lng}" for lat, lng in rounded]
        cached_vals = await self.redis.mget(*redis_keys)

        for i, val in enumerate(cached_vals):
            if val is not None:
                results[rounded[i]] = float(val)
            else:
                missing_points.append(rounded[i])

        if not missing_points:
            return [results[r] for r in rounded]

        # مرحله ۳: بررسی PostgreSQL برای نقاط باقی‌مانده
        placeholders = ",".join(
            [f"({lat},{lng})" for lat, lng in missing_points]
        )
        sql = text(f"""
            SELECT lat_rounded, lng_rounded, elevation_m
            FROM elevation_cache
            WHERE (lat_rounded, lng_rounded) IN ({placeholders})
        """)
        rows = await self.db.execute(sql)
        db_missing = list(missing_points)

        async with self.redis.pipeline() as pipe:
            for row in rows:
                key = (row.lat_rounded, row.lng_rounded)
                results[key] = float(row.elevation_m)
                db_missing.remove(key)
                # ذخیره در Redis برای دفعات بعد
                await pipe.set(
                    f"elev:{key[0]},{key[1]}",
                    str(row.elevation_m),
                    ex=None  # ارتفاع هرگز expire نمی‌شود
                )
            await pipe.execute()

        # مرحله ۴: فقط نقاطی که واقعاً گم هستند را از API بگیریم
        if db_missing:
            new_elevations = await self._fetch_elevations_from_api(db_missing)

            # ذخیره در PostgreSQL (دائمی)
            insert_values = []
            for (lat, lng), elev in new_elevations.items():
                insert_values.append(f"({lat}, {lng}, {elev}, 'opentopodata')")

            if insert_values:
                await self.db.execute(text(f"""
                    INSERT INTO elevation_cache (lat_rounded, lng_rounded, elevation_m, source)
                    VALUES {','.join(insert_values)}
                    ON CONFLICT (lat_rounded, lng_rounded) DO NOTHING
                """))
                await self.db.commit()

            # ذخیره در Redis (سریع)
            async with self.redis.pipeline() as pipe:
                for (lat, lng), elev in new_elevations.items():
                    await pipe.set(f"elev:{lat},{lng}", str(elev))
                    results[(lat, lng)] = elev
                await pipe.execute()

        return [results[r] for r in rounded]

    async def _fetch_elevations_from_api(
        self, points: List[tuple]
    ) -> Dict[tuple, float]:
        """دریافت ارتفاع از OpenTopoData به صورت batch"""
        results = {}
        for i in range(0, len(points), 100):  # هر بار 100 نقطه
            batch = points[i:i + 100]
            loc_str = "|".join([f"{lat},{lng}" for lat, lng in batch])
            try:
                resp = await self.http.get(
                    f"https://api.opentopodata.org/v1/srtm30m?locations={loc_str}"
                )
                for j, result in enumerate(resp.json()['results']):
                    results[batch[j]] = result['elevation']
            except Exception as e:
                print(f"Elevation API error: {e}")
                for pt in batch:
                    results[pt] = 0.0

            if i + 100 < len(points):
                await asyncio.sleep(1.1)  # rate limit رایگان

        return results

    # ─────────────────────────────────────────────
    # Google Directions — هندسه دائمی
    # ─────────────────────────────────────────────

    async def get_google_route(self, origin: dict, destination: dict) -> dict:
        """
        مسیر Google Directions — فقط هندسه (polyline، waypoints، سرعت مجاز).
        ترافیک حذف شده: تأثیری بر مصرف انرژی ندارد.
        جاده هرگز عوض نمی‌شود → یک‌بار از API، برای همیشه در DB.
        """
        o_lat = round(origin['lat'], 3)
        o_lng = round(origin['lng'], 3)
        d_lat = round(destination['lat'], 3)
        d_lng = round(destination['lng'], 3)
        redis_key = f"groute:{o_lat},{o_lng}:{d_lat},{d_lng}"

        # Layer 1: Redis (30 روز)
        cached = await self.redis.get(redis_key)
        if cached:
            return json.loads(cached)

        # Layer 2: PostgreSQL (دائمی)
        row = (await self.db.execute(text("""
            SELECT polyline, waypoints, distance_m, speed_limits
            FROM google_directions_cache
            WHERE origin_lat=:o_lat AND origin_lng=:o_lng
              AND dest_lat=:d_lat   AND dest_lng=:d_lng
        """), {"o_lat": o_lat, "o_lng": o_lng,
               "d_lat": d_lat, "d_lng": d_lng})).fetchone()

        if row:
            geo = {
                "polyline":    row.polyline,
                "waypoints":   row.waypoints,
                "distance_m":  row.distance_m,
                "speed_limits": row.speed_limits,
            }
            await self.redis.setex(redis_key, 86400 * 30, json.dumps(geo))
            return geo

        # Layer 3: Google API — یک‌بار، برای همیشه
        # departure_time حذف شد — ترافیک به مصرف انرژی ربط ندارد
        raw = await self._call_google_directions(origin, destination)
        geo = {
            "polyline":    raw["polyline"],
            "waypoints":   raw["waypoints"],
            "distance_m":  raw["distance_m"],
            "speed_limits": raw.get("speed_limits"),
        }

        # ذخیره دائمی در DB
        await self.db.execute(text("""
            INSERT INTO google_directions_cache
                (origin_lat, origin_lng, dest_lat, dest_lng,
                 distance_m, polyline, waypoints, speed_limits)
            VALUES (:o_lat,:o_lng,:d_lat,:d_lng,:dist,:poly,:wp,:sl)
            ON CONFLICT (origin_lat,origin_lng,dest_lat,dest_lng)
            DO UPDATE SET
                polyline=EXCLUDED.polyline,
                waypoints=EXCLUDED.waypoints,
                fetched_at=NOW()
        """), {
            "o_lat": o_lat, "o_lng": o_lng,
            "d_lat": d_lat, "d_lng": d_lng,
            "dist": geo["distance_m"],
            "poly": geo["polyline"],
            "wp":   json.dumps(geo["waypoints"]),
            "sl":   json.dumps(geo["speed_limits"]),
        })
        await self.db.commit()
        await self.redis.setex(redis_key, 86400 * 30, json.dumps(geo))

        return geo

    # ─────────────────────────────────────────────
    # مسیریابی
    # ─────────────────────────────────────────────

    async def get_route(self, origin: dict, destination: dict) -> dict:
        """دریافت مسیر — کش سه لایه‌ای"""
        # کلید با دقت ۳ رقم اعشار (~110 متر)
        o_lat = round(origin['lat'], 3)
        o_lng = round(origin['lng'], 3)
        d_lat = round(destination['lat'], 3)
        d_lng = round(destination['lng'], 3)
        redis_key = f"route:{o_lat},{o_lng}:{d_lat},{d_lng}"

        # Layer 1: Redis
        cached = await self.redis.get(redis_key)
        if cached:
            return json.loads(cached)

        # Layer 2: PostgreSQL
        result = await self.db.execute(text("""
            SELECT polyline, waypoints, distance_m, duration_s, speed_profile
            FROM route_cache
            WHERE origin_lat=:o_lat AND origin_lng=:o_lng
              AND dest_lat=:d_lat   AND dest_lng=:d_lng
              AND expires_at > NOW()
        """), {"o_lat": o_lat, "o_lng": o_lng, "d_lat": d_lat, "d_lng": d_lng})
        row = result.fetchone()

        if row:
            route_data = {
                "polyline": row.polyline,
                "waypoints": row.waypoints,
                "distance_m": row.distance_m,
                "duration_s": row.duration_s,
                "speed_profile": row.speed_profile,
            }
            # بارگذاری به Redis
            await self.redis.setex(redis_key, 86400 * 7, json.dumps(route_data))
            return route_data

        # Layer 3: API خارجی
        route_data = await self._fetch_route_from_api(origin, destination)

        # ذخیره در PostgreSQL
        await self.db.execute(text("""
            INSERT INTO route_cache
                (origin_lat, origin_lng, dest_lat, dest_lng,
                 distance_m, duration_s, polyline, waypoints, speed_profile)
            VALUES (:o_lat, :o_lng, :d_lat, :d_lng,
                    :dist, :dur, :poly, :wp, :sp)
            ON CONFLICT (origin_lat, origin_lng, dest_lat, dest_lng)
            DO UPDATE SET
                polyline=EXCLUDED.polyline,
                waypoints=EXCLUDED.waypoints,
                fetched_at=NOW(),
                expires_at=NOW() + INTERVAL '180 days'
        """), {
            "o_lat": o_lat, "o_lng": o_lng, "d_lat": d_lat, "d_lng": d_lng,
            "dist": route_data['distance_m'],
            "dur": route_data['duration_s'],
            "poly": route_data['polyline'],
            "wp": json.dumps(route_data['waypoints']),
            "sp": json.dumps(route_data.get('speed_profile')),
        })
        await self.db.commit()

        # ذخیره در Redis
        await self.redis.setex(redis_key, 86400 * 30, json.dumps(route_data))

        return route_data

    # ─────────────────────────────────────────────
    # آب‌وهوا
    # ─────────────────────────────────────────────

    async def get_weather(self, lat: float, lng: float) -> dict:
        """
        آب‌وهوا با TTL کوتاه — فقط ذخیره تا ۲ ساعت.
        چون آب‌وهوا تغییر می‌کند، در PostgreSQL نگه می‌داریم
        اما فقط برای ۲ ساعت معتبر است.
        """
        lat_r = round(lat, 2)
        lng_r = round(lng, 2)
        hour_bucket = datetime.now().replace(minute=0, second=0, microsecond=0)
        redis_key = f"weather:{lat_r},{lng_r}:{hour_bucket.hour}"

        # Layer 1: Redis (1 ساعت)
        cached = await self.redis.get(redis_key)
        if cached:
            return json.loads(cached)

        # Layer 2: PostgreSQL (2 ساعت)
        result = await self.db.execute(text("""
            SELECT temperature_c, wind_speed_ms, wind_dir_deg,
                   pressure_hpa, humidity_pct
            FROM weather_cache
            WHERE lat_rounded=:lat AND lng_rounded=:lng
              AND hour_bucket=:hour AND expires_at > NOW()
        """), {"lat": lat_r, "lng": lng_r, "hour": hour_bucket})
        row = result.fetchone()

        if row:
            weather = {
                "temperature_c": float(row.temperature_c or 20),
                "wind_speed_ms": float(row.wind_speed_ms or 0),
                "wind_dir_deg": int(row.wind_dir_deg or 0),
                "pressure_hpa": float(row.pressure_hpa or 1013),
            }
            await self.redis.setex(redis_key, 3600, json.dumps(weather))
            return weather

        # Layer 3: Open-Meteo API
        weather = await self._fetch_weather_from_api(lat, lng)

        # ذخیره در PostgreSQL
        await self.db.execute(text("""
            INSERT INTO weather_cache
                (lat_rounded, lng_rounded, hour_bucket,
                 temperature_c, wind_speed_ms, wind_dir_deg, pressure_hpa)
            VALUES (:lat, :lng, :hour, :temp, :wind, :wdir, :press)
            ON CONFLICT (lat_rounded, lng_rounded, hour_bucket)
            DO UPDATE SET
                temperature_c=EXCLUDED.temperature_c,
                wind_speed_ms=EXCLUDED.wind_speed_ms,
                wind_dir_deg=EXCLUDED.wind_dir_deg,
                expires_at=NOW() + INTERVAL '2 hours'
        """), {
            "lat": lat_r, "lng": lng_r, "hour": hour_bucket,
            "temp": weather['temperature_c'],
            "wind": weather['wind_speed_ms'],
            "wdir": weather['wind_dir_deg'],
            "press": weather['pressure_hpa'],
        })
        await self.db.commit()

        # ذخیره در Redis
        await self.redis.setex(redis_key, 3600, json.dumps(weather))

        return weather
```

## ۶. Orchestrator اصلی (با استفاده از SmartCache)

```python
# orchestrator.py
class RouteAnalyzer:
    def __init__(self, cache: SmartCacheService):
        self.cache = cache

    async def analyze(self, origin, destination, vehicle, options):
        # ۱. مسیر — از Cache یا OSRM
        route = await self.cache.get_route(origin, destination)

        # ۲. نمونه‌گیری هوشمند با الگوریتم RDP
        #    به جای هر 100 متر یک نقطه، فقط نقاط «مهم» مسیر انتخاب می‌شوند
        #    (جاهایی که شیب یا جهت تغییر می‌کند)
        #    برای 450 کیلومتر: از ~4500 نقطه به ~200-400 نقطه کاهش می‌یابد
        sample_points = self.smart_sample_route(
            route['waypoints'],
            max_points=400,          # سقف نقاط برای ارتفاع‌سنجی
            rdp_epsilon=0.001        # حساسیت تشخیص تغییر مسیر
        )

        # ۳. ارتفاع — فقط نقاط ناشناخته از API، بقیه از DB
        elevations = await self.cache.get_elevations(sample_points)

        # ۴. آب‌وهوا — فقط 3 نقطه نماینده (ابتدا، وسط، انتها)
        weather_points = await self._get_weather_along_route(sample_points)

        # ۵. ایستگاه‌های شارژ — از DB (sync هفتگی)
        chargers = await self.cache.get_chargers_near_route(sample_points)

        # ۶. محاسبه مصرف
        segments = self.calculate_consumption(
            route, sample_points, elevations, weather_points, vehicle
        )

        # ۷. برنامه‌ریزی شارژ
        charge_plan = self.plan_charging(segments, vehicle, chargers, options)

        return self.build_response(segments, charge_plan, chargers, route)

    def smart_sample_route(
        self,
        waypoints: List[tuple],
        max_points: int = 400,
        rdp_epsilon: float = 0.001
    ) -> List[tuple]:
        """
        الگوریتم Ramer-Douglas-Peucker (RDP) برای کاهش نقاط مسیر.

        ایده: نقاطی که روی یک خط مستقیم هستند حذف می‌شوند.
        فقط نقاطی که مسیر در آن‌ها «زانو» می‌زند نگه داشته می‌شوند.

        مثال برای تهران-اصفهان:
          قبل از RDP: 4500 نقطه → 45 API call
          بعد از RDP:  280 نقطه →  3 API call
          صرفه‌جویی: 93%
        """
        if len(waypoints) <= 2:
            return waypoints

        def rdp(points, epsilon):
            if len(points) < 3:
                return points
            # پیدا کردن دورترین نقطه از خط اول-آخر
            start, end = points[0], points[-1]
            max_dist, max_idx = 0.0, 0
            for i in range(1, len(points) - 1):
                # فاصله عمودی نقطه از خط
                dx = end[0] - start[0]
                dy = end[1] - start[1]
                if dx == 0 and dy == 0:
                    dist = ((points[i][0]-start[0])**2 + (points[i][1]-start[1])**2)**0.5
                else:
                    t = ((points[i][0]-start[0])*dx + (points[i][1]-start[1])*dy) / (dx*dx+dy*dy)
                    t = max(0, min(1, t))
                    proj = (start[0]+t*dx, start[1]+t*dy)
                    dist = ((points[i][0]-proj[0])**2 + (points[i][1]-proj[1])**2)**0.5
                if dist > max_dist:
                    max_dist, max_idx = dist, i

            if max_dist > epsilon:
                left  = rdp(points[:max_idx+1], epsilon)
                right = rdp(points[max_idx:],   epsilon)
                return left[:-1] + right
            return [start, end]

        reduced = rdp(waypoints, rdp_epsilon)

        # اگر هنوز بیشتر از max_points بود، epsilon را بزرگ‌تر کن
        if len(reduced) > max_points:
            reduced = rdp(waypoints, rdp_epsilon * 3)

        return reduced

    async def _get_weather_along_route(self, points):
        """فقط 3 نقطه: ابتدا، وسط، انتها — interpolate بین آن‌ها"""
        n = len(points)
        indices = [0, n // 2, n - 1]
        tasks = [self.cache.get_weather(points[i][1], points[i][0]) for i in indices]
        weather_data = await asyncio.gather(*tasks)
        return self._interpolate_weather(weather_data, n)
```

## ۱۰. موتور محاسبه مصرف انرژی

### ۱۰.۱ فرمول اصلی

```
E_total = E_base + E_slope + E_aero + E_thermal

E_base    = (consumption_kwh_per_100km / 100) × d_km
E_slope   = (m × g × Δh) / (3,600,000 × η_drivetrain)
E_aero    = (0.5 × ρ × Cd × A × v_rel²) × d / (3,600,000 × η_drivetrain)
E_thermal = HVAC_load_kw × (d_km / avg_speed_kmh)
```

| متغیر | توضیح | مقدار نمونه |
|-------|-------|------------|
| `m` | وزن خودرو + سرنشینان (kg) | 1800 |
| `g` | شتاب گرانش (m/s²) | 9.81 |
| `Δh` | اختلاف ارتفاع — از elevation_cache | متغیر |
| `η_drivetrain` | راندمان درایوترین | 0.90 |
| `ρ` | چگالی هوا — از ارتفاع + دما | ~1.225 |
| `Cd` | ضریب پسا آیرودینامیک | 0.23-0.35 |
| `v_rel` | سرعت نسبی خودرو و باد — از weather_cache | متغیر |

### ۱۰.۲ ریجنریشن سرازیری

```
اگر Δh < 0:
  E_regen = |E_slope| × 0.65 × 0.92
  E_net   = E_slope + E_regen   ← منفی یعنی انرژی برگشتی
```

### ۱۰.۳ اثر دما

```python
def battery_temp_factor(temp_c):
    if temp_c < 0:   return 0.70 + temp_c / 20 * 0.15
    if temp_c < 15:  return 0.85 + temp_c / 15 * 0.10
    if temp_c < 35:  return 1.0
    return 1.0 - (temp_c - 35) * 0.005

def hvac_load_kw(temp_c, target=22):
    delta = abs(temp_c - target)
    if delta < 3:   return 0.2
    if delta < 10:  return 1.5
    if delta < 20:  return 2.8
    return 4.5
```
